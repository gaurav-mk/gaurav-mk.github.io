# JESD204B Standard at a Glance
- A standardized serial interface between data converters (ADCs and
DACs) and logic devices (FPGAs or ASICs)
- Serial data rates up to 12.5 Gbps
- Mechanism to achieve deterministic latency across the serial link
- Uses 8b/10b encoding for SerDes synchronization, clock recovery and
DC balance
- JESD204B is a must for ***high density systems!***

### The Legacy LVDS Architecture

The left schematic shows a standard [Low Voltage Differential Signaling](https://en.wikipedia.org/wiki/Low-voltage_differential_signaling) driver array.

- **Throughput per lane:** **1.25 GB/s**
- **Required lanes for 40 GB/s:** **32**
- **Current draw per lane:** **3.5mA**
- **Total Current Draw:** 32 multiplied by 3.5mA equals **112mA**

### The Modern JESD204B Architecture

The right schematic shows a [Current Mode Logic](https://en.wikipedia.org/wiki/Current_mode_logic) driver used in JESD204B systems. Because it runs at significantly higher frequencies, it requires a dedicated Phase Locked Loop block to synthesize the clock and serialize the data.

- **Throughput per lane:** **10 GB/s**
- **Required lanes for 40 GB/s:** **4**
- **Current draw per lane:** **16mA**
- **Total driver current:** 4 multiplied by 16mA equals **64mA**
- **Phase Locked Loop overhead:** **50mA**
- **Total Current Draw:** 64mA plus 50mA equals **114mA**
