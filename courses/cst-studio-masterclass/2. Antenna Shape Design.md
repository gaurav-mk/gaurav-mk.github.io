> [!abstract] Key idea
> Models are built from shapes defined by **coordinates**. Tie those coordinates to **variables** and the whole design can be resized from one place.

## 0.1 Brick Shape
- A **brick** is a 3D box, the basic building block for flat layers such as patches, substrates and ground planes.
- It is set by a **minimum and maximum coordinate on each axis**, so size = max - min.
- The Z range sets the **thickness** of the material.

## 0.2 Centering at the Origin
- Put **half the size on each side of the origin**.
- Example: a width of 2 runs from -1 to 1, and a length of 4 runs from -2 to 2.
- A centered shape stays centered when it is resized.

## 0.3 Parameters
- Replace numbers with **variables** such as W, L and h.
- When you type a new variable, CST asks for its **value** and a **description**.
- One change in the **Parameter List** then resizes everything that uses that variable.
- This is what makes tuning and [[3. Patch Antenna Design|parametric sweeps]] possible.

## 0.4 Material and Color
> [!grid]
> > [!info] Color
> > Only changes how the shape **looks on screen**. It doesn't affect the results.
>
> > [!warning] Material
> > Sets the **electrical properties** used by the solver, so it changes the results.

Both are set by right-clicking the shape -> Change Material and Color.

## 0.6 Cylinder Shape
- A **cylinder** makes circular shapes, such as round patches and rings.
- An **inner radius** above 0 cuts a hole in the middle, which makes a ring.
- **Segments** turns the circle into a polygon, so one tool gives triangles, squares and hexagons.
- A thickness of 0 gives a **flat disc**.

## 0.8 Copying Shapes
- **Transform** makes copies, so a repeated feature is only drawn once.
- **Mirror** flips a copy across a plane, which suits matching slots on opposite sides.
- **Translate** moves a copy by a set distance. The **repetition factor** makes several copies at once.
- For evenly spaced holes, center spacing **D = 2r + gap**. Holes with r = 0.5 and a 0.5 gap need D = 1.5.

## 0.9 Slots and Holes
- A **slot** is a small brick subtracted from a patch. A **hole** is a small cylinder subtracted from it.
- Slots are placed with variables: length **SL**, width **SW**, and gap **g** from the patch edge.
- Several cutters can be subtracted in one step.
- Press **M** then **W** to move the axes to the middle of an edge, so a slot can be positioned from that point. Turn **Local WCS** off afterwards.
- Patches here are **copper**, loaded from the material library, 0.035 mm thick.
