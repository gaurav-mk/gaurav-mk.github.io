> [!abstract] Key idea
> A **frequency selective surface (FSS)** is a repeating pattern that acts as a **filter for electromagnetic waves**. It reflects some frequencies and lets others through. Design one unit cell first, then repeat it.

- An FSS is a **periodic structure**: one **unit cell** repeated in a grid.
- The cell's shape, spacing and materials set which frequencies pass and which are blocked.
- Small changes to any dimension change the whole surface's response.
- **Uses:** antennas, radomes, stealth, EM shielding, satellite links and wireless filters.

> [!warning] Square loops
> The lecture lists square loops as bandpass, but a single **metal** loop blocks a band, as this section's own design shows. Bandpass needs **openings** in a metal sheet, or several resonators working together, as in [[6. Bandpass FSS Design|Section 6]].

## 0.3 Convoluted Square Loop Unit Cell
- This design is a **convoluted square loop (CSL)**: a square copper loop with a curve in each side.
- **Goal:** block the **X band (8 to 12 GHz)** and pass the rest.
- **Substrate:** Rogers RT/duroid 5880, a flexible laminate, so the FSS can sit on curved surfaces.
- **Conductor:** copper, 0.035 mm thick. Use the **lossy** library materials, because real materials have loss.
