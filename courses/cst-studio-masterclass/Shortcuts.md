## 0.2 What Each One Does
| Key | Action | Used for | Video |
|---|---|---|---|
| **S** | Measure | Press S, then double-click an edge to read its length | 4 |
| **D** | Clear picks | Removes the current selection | 4 |
| **M** | Midpoint | Picks the middle of an edge | 9 |
| **E** | Pick edge | Selects an edge, to read its length | 27 |
| **P** | Pick point | Selects a point, to read the distance between two points | 27 |
| **F** | Pick face | Selects a face | 53 |
| **W** | Move axes | Moves the axes to the picked point | 9 |
| **Space** | Reset view | Refits the model, or a plot after zooming | 14 |
| **Esc** | Type coordinates | Opens the dialog after choosing a shape tool, instead of drawing with the mouse | 4 |
| **Enter** | Confirm | Finishes the shape selection in a Boolean operation | 6 |
| **F7** | Parametric Update | Applies changed parameter values to the model | 4 |
| **Ctrl + click** | Select several | Selects more than one shape, for example before Boolean Add | 18 |
| **R** | Point on circle | Picks a point on a curved edge, for example to check a radius | 111 |
| **A** | Face center | Picks the center of a face, for example the two ends of a port gap | 111 |

## 0.3 Common Sequences
- **Check a dimension:** S, double-click an edge, read it, then D.
- **Place a shape on an edge:** M, W, then draw the shape. Turn Local WCS off afterwards.
- **Draw an exact shape:** choose the tool, Esc, then type the coordinates.
- **Resize the model:** change a value in the Parameter List, then F7.
- **Check a ring's width:** R on the outer edge, R on the inner edge, then read the distance.
- **Place a discrete port across a gap:** A on one end face, A on the other, then add the port.
