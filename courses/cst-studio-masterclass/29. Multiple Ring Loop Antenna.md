> [!abstract] Key idea
> This antenna puts two **closed parasitic rings** around a fed ring. They aren't connected to the port, but they couple to it, like the parasitic elements of a [[23. Yagi Uda Antenna|Yagi]]. The result is a better match than a single ring, at -9.4 dB against -6.6 dB, and a slightly narrower beam.

- **Match:** -9.36 dB corresponds to about **100 Ω**, down from about 140 Ω for the single ring, and closer to 50 Ω.
- **Frequency:** the 1.08 λ rule from [[28. Circular Loop Antenna|Section 28]] puts the inner ring alone near 3.7 GHz, but the dip is at 3.10 GHz. So the outer rings seem to pull it down.
- **Current:** the surface current plot shows the inner ring carrying most of the current, and the outer rings far less. So they mainly load the fed ring.

> [!tip] Two tests worth running
> The lecture doesn't simulate the inner ring alone, so the 3.7 GHz figure is only an estimate. Running it would show exactly what the outer rings add. Sweeping **G2** would also be useful, because that gap sets the coupling, and a slightly stronger effect may clear -10 dB.

- S11 stays near 0 dB below about 2.4 GHz, so there's one main band, and it starts falling again near 6 GHz.
- At -9.36 dB the antenna accepts **88%** of the power, so the lecture's "almost 90%" is fair this time.

> [!warning] Same two conclusions to correct
> The lecture calls the pattern almost a doughnut, but the 1D plot **peaks along the axis**, so it's the broadside pattern from [[27. Rectangular Loop Antenna|Section 27]]. It also says the antenna suits only short-range RFID. A 12% power loss doesn't limit it to that, and this loop isn't electrically small.

> [!note] Efficiency above 100%
> The radiation efficiency reads +0.012 dB. PEC has no loss, so that tiny excess is numerical noise, like the gain in Section 23.

## 0.4 The Three Loops Compared
| | Square | Single ring | Three rings |
|---|---|---|---|
| Dip | 3.06 GHz | 3.15 GHz | 3.10 GHz |
| Deepest S11 | -6.95 dB | -6.62 dB | -9.36 dB |
| Impedance from S11 | About 130 Ω | About 140 Ω | About 100 Ω |
| Directivity at 3 GHz | 3.39 dBi | 3.53 dBi | 3.97 dBi |
| 3 dB beamwidth | 128.6° | 126.9° | 107° |
| Overall width | 29 mm | 33.8 mm | 48 mm |

- The extra rings buy a better match and about 0.4 dB more directivity than the single ring.
- The cost is **size**: the antenna is about 0.5 λ across.
